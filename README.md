## Projects

### HALIGTREE

A long-term local intelligence project built to persist across my machines, understand what is happening around it, use and create tools, control devices, research independently, and eventually extend into physical hardware and robotics.

### Omoio Together

Rebuilding Omoio into a public multiplayer platform for emulated games.

One machine hosts the game through emulators such as RPCS3, Dolphin or Cemu while other players join remotely from PCs or phones, receive the game stream, and connect as their own controller/player.

### Real-to-Sim Learning for Dexterous Manipulation

BSc dissertation using human-motion demonstrations and Unity ML-Agents to train a simulated KUKA iiwa7 and SCHUNK SVH hand with Behavioural Cloning and PPO.

### ML-Agents Navigation vs NavMesh

Research project comparing PPO-trained navigation against conventional Unity NavMesh navigation.
