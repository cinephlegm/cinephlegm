## ✦ The Canopy

I build games first, then go as deep as the project needs.

That usually means gameplay systems, engine/tooling work, AI agents, reverse engineering, emulation tooling, multiplayer/networking, Android/TV apps, robotics-adjacent experiments, or whatever technical layer sits underneath the idea.

---

## ✦ In Bloom

### HALIGTREE

A long-term local intelligence project focused on persistence across machines, tool use, research, orchestration, memory/state, and eventual hardware and robotics integration.

### Omoio Together

Ground-up rebuild of Omoio into a public multiplayer platform for emulated games.

One machine hosts through RPCS3, Dolphin, or Cemu while remote players join from PC or phone, receive the stream, and connect as their own controller/player.

### OVERGROWTH

Private game project focused on atmosphere, traversal, environmental storytelling, and technical presentation.

---

## ✦ Public Work

### [Real-to-Sim Reaching Benchmark](https://github.com/cinephlegm/real-to-sim-reaching-benchmark)

BSc dissertation project comparing Behavioural Cloning and PPO refinement for robotic reaching in Unity ML-Agents using a simulated KUKA iiwa7 and SCHUNK SVH hand.

### [ML-Agents Navigation vs NavMesh](https://github.com/cinephlegm/ml-agents-navigation-vs-navmesh)

Research project comparing a raycast-based PPO navigation agent against a conventional Unity NavMesh baseline in a constrained indoor environment.

### [Arin's Adventure](https://github.com/cinephlegm/arins-adventure)

2D C++ adventure game built with raylib and Tiled, with a full Windows release package.
